## What's Inside Each Lab
Every lab folder follows a consistent documentation standard:
- **Topology diagram** (`.png`) and **Packet Tracer file** (`.pkt`)
- **Exported device configurations** (`running-config` for routers and switches)
- **Addressing table** and **key verification commands** (`show` outputs)
- **Troubleshooting log** documenting issues encountered and resolved
